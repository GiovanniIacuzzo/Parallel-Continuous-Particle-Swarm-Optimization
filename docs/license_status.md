# Licensing status

The current source archive does not contain a `LICENSE` file. The previous
package metadata declared MIT without a corresponding license text or an
explicitly confirmed copyright holder. To avoid asserting a license that has
not been authorized, the `license` declaration has been removed from
`pyproject.toml` pending owner confirmation.

Before public release, the project owner must decide whether the intended
license is MIT or another license, confirm the copyright holder(s) and year,
add the complete license text, and restore matching package metadata. Until
then, the repository must not be presented as MIT-licensed or assumed to be
open-source under a permissive license.
