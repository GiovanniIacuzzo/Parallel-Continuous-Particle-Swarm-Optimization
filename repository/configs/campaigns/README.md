# Campaign configurations

- `definitive_architecture_campaign.json`: predeclared multi-stage campaign
  (9,360 optimization runs and 273,888,000 objective evaluations; 30 search seeds and 10 timing seeds).
- `campaign_smoke.json`: small integration-only campaign for checking the
  orchestration, checkpointing and analysis pipeline. Never use its outputs
  for scientific conclusions.

See `docs/definitive_experimental_campaign.md` for the protocol and commands.
